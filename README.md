# HandTrack

Real-Time Hand Gesture Recognition Using Python.

## Description

HandTrack is a computer vision application that uses
a webcam to detect hands, count raised fingers and
recognize simple hand gestures in real time.

## Technologies

- Python
- OpenCV
- MediaPipe

## Features

- Real-time webcam capture
- Hand landmark detection
- Finger counting
- Hand gesture recognition
- Visual feedback


## Installation

### Prerequisites

- Python 3.12 (recommended)
- Git
- Webcam
- Windows, macOS, or Linux

### Setup

Clone the repository:

```bash
git clone https://github.com/17Yannick17/HandTrack.git
cd HandTrack
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment (Windows PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m src.main
```
