
# Changelog

All notable changes to HandTrack are documented here.

## [1.0.0] — Initial Release

### Added

- Real-time webcam capture using OpenCV.
- Hand detection and tracking using MediaPipe.
- Visualization of 21 hand landmarks.
- Finger counting from 0 to 5.
- Individual finger state detection.
- Recognition of Fist, Open Palm and Victory gestures.
- Unknown gesture classification.
- Temporal gesture stabilization.
- Interactive visual feedback for recognized gestures.
- Color-coded ALERT, READY and SUCCESS states.
- Action event counter.
- Automated unit tests using pytest.
- GitHub Actions continuous integration.
- Installation and technical documentation.
- Application demonstration.

### Known Limitations

- Single-hand tracking only.
- Recognition depends on lighting and hand orientation.
- Finger counting relies on 2D geometric heuristics.
- No control of external applications.
- No persistent action history.
